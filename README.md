# Unity-ar-mobile-app
An Android-based augmented reality mobile application developed in Unity, featuring custom 3D models created in Blender and integrated using the EasyAR SDK.

## About
This project was developed for the Android platform to explore mobile AR implementation. Key technologies and tools include:
- Unity 3D Development
- EasyAR SDK for AR functionality
- 3D Modeling and design using Blender
